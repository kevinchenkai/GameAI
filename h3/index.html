关于 MiniMax-H3

MiniMax-H3 是 MiniMax 开源的视频生成模型，特点是原生同时生成画面与音频—— 对白、环境声与配乐在一次推理里同时产出，不需要事后配音。 模型主页：Hugging Face · GitHub · ModelScope。

五种生成模式

T2VA 纯文生视频 · I2VA 单图驱动 · FL2VA 首尾帧驱动 · L2VA 尾帧驱动 · Ref2VA 参考图 / 参考视频 / 参考音频驱动

画面与音频同源

音频不是后期贴上去的：prompt 里描述的音效节点会与画面事件对齐， 口型也能与新增对白同步。

帧数走固定网格

可用帧数为 17k+5：107 / 124 / … / 362。 最长约 15.08 秒，本站 C-004 就是跑在 362 帧上限。

原生分辨率

768 为短边，横屏 1344×768、竖屏 768×1344。 本站成片全部按原生分辨率直出，未做放大。

需要说明的是：官方托管服务里有一层名为 H3-Context-IR 的提示词预处理， 开源版本并不包含。因此网上流传的一些很短的 prompt 在开源版直跑， 效果会与演示不同 —— 本站所有 prompt 都是在开源版上实际跑通的原文。 官方写作规范见 Prompt Writing Guide， 本地部署见 ComfyUI 官方教程。

结构化长 prompt（D 系列）

同一作者、同一套写法模板的四条长 prompt，全部 15 秒满帧长。 它们把镜头结构写死在文本里（分几段、在哪里切、每段用什么焦段）， 用来看模型对显式分镜指令的执行程度。 每条都跑了两个 seed —— 结论只在两个 seed 一致时才作数。
