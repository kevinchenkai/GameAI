# 发布前备份

`pre-release-2026-10-09/` 保存本次目录整理移出的非发布资料，所有原始文件均保留。

| 路径 | 内容 |
|---|---|
| `documents/` | V2–V5 验证记录、内容来源、选材记录与图片生成提示词 |
| `research/` | 历史研究记录、旧采集目标和本地原文缓存 |
| `legacy/scripts/` | 已由当前构建或采集流程替代的旧工具 |
| `original/` | 整理前 README、部署脚本、忽略规则和工具原稿 |
| `local/output/` | 截图、预览和历史部署校验等本地临时产物 |
| `original-inventory.json` | 整理前所有文件的 SHA-256、大小与 Git 跟踪状态 |
| `manifest.json` | 每项移动／原稿快照的原路径、现路径与校验值 |

原路径以 `apec26/` 为基准。按 `manifest.json` 可以定位原稿并恢复原目录；运行文件现位于 `public/`，已审核来源位于 `data/sources/`。当前构建工具已适配这些新路径，不依赖本备份。

历史脚本按原样保存，仅供追溯；其中路径对应整理前结构，日常维护使用主目录 `scripts/` 中的工具。原文缓存、截图和系统临时文件仍只保存在本地，继续被 Git 忽略。不要将备份目录作为网站根目录或部署源。
