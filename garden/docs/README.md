## 三条最贵的教训（详见开发日志 §1）

放在这里是因为它们**反复出现**，值得每次开工前扫一眼：

1. **单测全绿 ≠ 渲染层没问题** —— 本阶段出现 4 次以上。
   数据对、**接缝**错。渲染层改动必须浏览器实跑，且**读运行时状态**而非只看截图。
2. **"算过" ≠ "画出来没问题"** —— 规格自洽的色板，画出来可能因高光阴影而撞色。
   凡"能不能看清"的判据，测试必须**读真实 PNG 像素**。
3. **度量口径必须和规格用同一个** —— 我用 BT.601 量 BT.709 的规格，
   得出"交付图不达标"的错误结论，还据此写了工单（已作废）。
