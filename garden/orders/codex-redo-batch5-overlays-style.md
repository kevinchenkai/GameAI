## 0. 一句话

3 张标记（横火箭 / 竖火箭 / 炸弹）**可读性合格但风格与棋子脱节** ——
水果是柔和 3D，标记是硬边剪贴画。要的是**同一套画风**，不是更醒目。

---

## 1. 用户原话与现状

用户实测反馈：**"横向、纵向的箭头，炸弹，好难看，这个要重点优化。"**

当前三张贴到六色棋子上的实际样子：

- **横/竖火箭**：一根**双向箭头**（两端尖角），金色芯 + 深棕硬描边
- **炸弹**：一个**细金圈** + 右上角小星星 —— 读起来像装饰边框，不像"会爆炸的东西"

---

## 2. 🔴 关键诊断：问题不是"太扁平"，是**对比过硬**

我量了像素，结论和直觉相反 —— **不要按"加点立体感"去改**：

| 素材 | 明暗跨度（P95−P05） |
| --- | ---: |
| `overlay-rocket-h` | **210.0** |
| `overlay-rocket-v` | **233.3** |
| `overlay-bomb` | **230.0** |
| — 参考 — | |
| `piece-red`（水果） | **50.8** |
| `piece-yellow`（水果） | **37.7** |

**标记的明暗跨度是水果的 4~6 倍。**

也就是说：标记不是"缺少层次"，而是**从纯深棕直接跳到亮金**，
中间没有过渡。水果则是在 40~50 的窄区间里做柔和渐变。

> 🔴 **两者放在一起，标记像是从另一个游戏里贴过来的。**
> 这就是"难看"的技术根源。

---

## 3. 要做什么

### 3.1 风格目标

与 `assets/pieces/piece-*.png` **同一套语言**：

| 项 | 要求 |
| --- | --- |
| 光影 | 柔和渐变过渡，**不要硬边纯色块** |
| 体积 | 有厚度、有环境光，像"放在棋子上的小物件" |
| 色调 | 暖色系，与水果同一个色温 |
| 描边 | 深色描边**保留**（§5.2 要求），但要**柔化**：加 1~2px 的过渡，不要刀切边 |

### 3.2 造型

| 素材 | ❌ 现在 | ✅ 要改成 |
| --- | --- | --- |
| `overlay-rocket-h.png` | 扁平双向箭头 | **有体积的小火箭**，横向放置，带柔和推进尾焰；或一道有厚度的横向能量束 |
| `overlay-rocket-v.png` | 同上，竖向 | 同上，竖向 |
| `overlay-bomb.png` | 细金圈 + 小星 | **有重量感的球体** + 引线（或明确的爆裂纹理）——**要让人一眼认出"这会炸"** |

> ⚠️ **火箭的方向必须一眼看出**。横向标记要明确指向左右、竖向指向上下 ——
> 这关系到玩家能否预测清除范围（框架 §5 特别提醒过这条，M8 要专门观察理解率）。

---

## 4. 🔴 不许违反的硬判据（§5.2）

**这一版可读性是达标的，重做时不能倒退。**

1. **深色描边 + 亮色芯**的双色结构**必须保留** ——
   这是唯一能同时对付浅色（香蕉）与深色（苹果）棋子的办法。
   柔化 ≠ 去掉。
2. **标记与其下棋子的灰度差 ≥ 20，六色全部满足**。
   ⚠️ 判据**不是**"棋子还认不认得出"，是"标记看不看得见"。
3. 标记**本体不透明度可以高**（80%+），靠**只占小面积**保证棋子仍可辨认 ——
   **不要**靠整体半透明。

> 🔴 **不要把 §5.1（冰块/遮挡层）的"淡而不饱和"套到这里。**
> 遮挡层怕盖死棋子，标记层怕自己看不见 —— **失败方向相反**。
> batch4 首版正是踩了这个：每个数字都达标，但香蕉上 Δ=5.7，等于没有标记。

### 4.1 面积约束

炸弹当前覆盖 **17.9%**、火箭约 **4.5%**。
重做后**火箭不超过 12%、炸弹不超过 25%** —— 再大就开始盖住水果本体。

## 5. 交付前自检（**请自己跑，不要让我来测**）

把每张标记**叠到六色棋子上**，逐色量"标记区域 vs 邻近棋子"的平均灰度差：

- 六色**全部 ≥ 20** 才算过
- ⚠️ **重点看香蕉（yellow）**，它是最浅的，历史上就是在这里失败的

同时附三张验收图（沿用 §5 的形式）：
1. 三种标记 × 六色棋子的**合成总览**
2. **40px 缩小图** —— 手机上标记只有这么大
3. **深色底** —— 确认描边在暗背景下不糊
