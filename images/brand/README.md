# Codex Games Brand Mark

## Active: V2 Neural C

The active mark uses three connected terminals to suggest AI connections and
learning, with a soft C silhouette, a mint body, and one coral terminal.
No play button, text, or detailed circuit drawing is used. Generated with the
built-in Image Gen tool; no fallback CLI or API key was used.

- `codex-games-v2.png`: 512 x 512 transparent master, normalized without
  changing the generated artwork.
- `codex-games-v2-96.webp`: lossless transparent header mark.
- `codex-games-v2-32.png`: browser favicon.
- `codex-games-v2-180.png`: touch icon.

The site and rebuild script use v2 filenames, bypassing the server's
30-day image cache. The superseded v1 draft was removed after acceptance.

All derived assets retain alpha. Rebuild them with
`node scripts/build-home-images.cjs` (requires Sharp). No generated-image API
or credentials are needed to run the site.
